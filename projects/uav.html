LiDAR UAV Collision Detection

This project explores collision detection and avoidance for UAV drones using reinforcement learning and LiDAR-based perception. A simulated drone was trained in a Unity environment to safely navigate toward a goal while avoiding obstacles using only LiDAR sensor inputs.

Project Overview

As part of a four-person team, this project aimed to design and train a simulated UAV drone capable of autonomous navigation and collision avoidance. A realistic 3D environment was built in Unity, including obstacles and environmental conditions, and a reinforcement learning pipeline was used to train the drone to reach a target location safely. The project demonstrates how LiDAR-based sensing and reinforcement learning can be combined for navigation in unknown environments.

Key Features

  • Unity-based simulation environment with realistic obstacles and flight physics
  • LiDAR-based sensing system using 3D point cloud data for environment perception
  • Reinforcement learning pipeline using Unity ML-Agents framework
  • Custom reward function to balance safety, efficiency, and goal completion
  • TensorBoard dashboard for tracking training progress and performance metrics

Dataset & Data Processing

LiDAR trajectory and sensor data were derived from external datasets and processed for use in the simulation. Data preprocessing included aggregation, interpolation, and visualization of 3D point cloud and trajectory data to better understand drone movement and sensor behavior.

Model Approach

A reinforcement learning agent was trained using the Unity ML-Agents framework. The drone receives LiDAR sensor data and state variables (position, velocity, orientation) as input and outputs control actions for pitch, roll, yaw, and altitude. A custom reward function encourages efficient navigation, penalizes collisions, and discourages inefficient paths. A multilayer perceptron (MLP) policy network was used due to computational constraints.

Training Progress

Results

The trained agent demonstrated steady improvement over time, with increasing reward values, reduced collision behavior, and smoother navigation trajectories. The final system achieved an overall success rate of approximately 72–75% in reaching the goal while avoiding obstacles. Training metrics showed reduced episode failures, fewer timeouts, and more consistent success episodes as learning progressed.
