Effective Invasive Plant Identification using Convolutional Neural Networks

This project applies convolutional neural networks (CNNs) to identify invasive plant species using image data from a Brazilian national forest. The goal is to improve early detection and response systems by automating plant classification and reducing reliance on manual inspection.

Project Overview

As part of a three-person team, this project evaluated multiple CNN architectures to determine the most effective model for classifying invasive plant species. Both pretrained models and a custom CNN were implemented and compared using performance metrics such as accuracy, precision, recall, F1-score, and confusion matrices. The project emphasizes model selection, handling imbalanced datasets, and improving classification performance for environmental applications.

Key Features

  • Comparison of five CNN architectures: VGG16, DenseNet, MobileNet, InceptionV3, and a custom model
  • Implementation of transfer learning for pretrained models
  • Custom CNN designed to reduce overfitting on a small, imbalanced dataset
  • Use of data augmentation and class weighting to improve generalization
  • Evaluation using accuracy, precision, recall, F1-score, and confusion matrices

Dataset

Kaggle Invasive Species Monitoring dataset containing labeled plant images. The dataset includes approximately 1,400+ images with class imbalance between invasive and non-invasive species. Data preprocessing included normalization, train/validation/test splitting, and data augmentation to improve model robustness.

Model Approach

Multiple CNN architectures were evaluated, including both pretrained models and a custom-built network. Transfer learning was used to leverage pretrained feature extractors, while the custom CNN was designed with three convolutional layers and dropout to reduce overfitting. Class weights and different classification thresholds were explored to balance precision and recall for detecting invasive species.

Results

The DenseNet model achieved the best overall performance, providing the strongest balance between precision and recall. While the MobileNet model achieved slightly higher accuracy, DenseNet produced the best F1 score and most reliable detection of invasive species. A lower classification threshold (0.4) was selected to prioritize recall and reduce missed detections, which is important for environmental monitoring tasks.
