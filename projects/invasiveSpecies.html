Pneumonia Detection with Spark-Based CNN

This project implements a distributed deep learning pipeline using Apache Spark to classify chest X-ray images as pneumonia or normal.

Key Features

  • Distributed preprocessing using PySpark
  • CNN model with batch normalization and dropout
  • Early stopping and model checkpointing
  • Multi-node Spark cluster (1 master, 3 workers)

Tools

Python, PyTorch, PySpark, NumPy
