Flower Image Classification Using Spark-Based Convolutional Neural Networks

This project explores distributed deep learning with Apache Spark to classify flower images using Convolutional Neural Networks (CNNs)

Key Features

  • Distributed preprocessing using PySpark
  • CNN model with data augmentation and dropout
  • Improves model over 4 scripts and evaluating the success of each
  • Two-node Spark cluster (1 master, 1 worker)

Tools

Python, PySpark, NumPy, Pandas
