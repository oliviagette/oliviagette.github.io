Flower Image Classification Using Spark-Based Convolutional Neural Networks

This project explores distributed deep learning with Apache Spark to classify flower images using Convolutional Neural Networks (CNNs). Using the Kaggle Flowers Recognition dataset, the model classifies images across five categories: daisy, dandelion, rose, sunflower, and tulip.

Project Overview

The goal of this project was to evaluate how distributed computing can support image preprocessing and CNN training across multiple virtual machines. Apache Spark was used for data handling and preprocessing, while PyTorch was used to train the CNN model.

Key Features

  • Distributed preprocessing using PySpark
  • Image resizing to 128x128 and normalization to [0,1]
  • CNN model with data augmentation, dropout, batch normalization, and learning rate scheduling
  • Iterative model improvement across four scripts
  • Two-node Spark cluster (1 master, 1 worker)

Dataset

Kaggle Flowers Recognition Dataset with five flower classes: daisy, dandelion, rose, sunflower, and tulip.

Results

The final CNN model achieved 77.5% test accuracy. Across four script iterations, the model improved through deeper convolutional layers, batch normalization, data augmentation, dropout, adaptive pooling, and a learning rate scheduler.
