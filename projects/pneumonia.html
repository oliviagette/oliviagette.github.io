Spark-Based Deep Convolutional Neural Network for Pneumonia Detection in Chest X-Rays

This project builds a distributed deep learning pipeline for pneumonia detection in chest X-ray images using Apache Spark for preprocessing and a custom Convolutional Neural Network (CNN) for classification. The goal was to demonstrate how distributed computing can support scalable medical imaging workflows in CPU-only environments.

Project Overview

As part of a two-person team, this project focused on classifying chest X-ray images as Normal or Pneumonia using a custom CNN trained on a large pediatric chest X-ray dataset. Apache Spark was used to build a distributed preprocessing pipeline capable of scanning image directories, extracting labels, and creating reproducible train, validation, and test manifests across a four-node cluster. PyTorch was then used to train and evaluate the CNN model.

Key Features

  • Distributed preprocessing with Apache Spark across a 4-node cluster (1 master, 3 workers)
  • Automated manifest generation for train, validation, and test splits using HDFS
  • Custom CNN with strided convolutions, batch normalization, dropout, and adaptive average pooling
  • Image augmentation including flips, rotations, affine transforms, and random crops
  • Regularization with both L1 and L2 penalties to reduce overfitting

Dataset

Kaggle Chest X-Ray Pneumonia dataset containing 5,856 labeled pediatric chest X-ray images. Although the original dataset includes three categories (Normal, Bacterial Pneumonia, and Viral Pneumonia), this project simplified the task to binary classification: Normal vs Pneumonia. Exploratory analysis showed substantial class imbalance, with pneumonia cases appearing much more frequently than normal cases, motivating careful evaluation and model regularization.

Model Approach

A custom CNN was developed to classify chest X-rays after distributed preprocessing in Spark. Instead of max pooling, the architecture used strided convolutions for downsampling to preserve spatial information. Batch normalization, dropout, adaptive average pooling, and both L1 and L2 regularization were incorporated to improve stability and reduce overfitting. Training was monitored with validation accuracy, and early stopping was used to keep the best-performing model.

Model Performance

Results

The best model achieved a validation accuracy of 94.65% at Epoch 4 before validation performance began to decline, indicating overfitting beyond that point. The final selected model achieved a test accuracy of 80.45%, with a test loss of 0.4222 and a weighted average F1-score of 0.81. The model showed strong performance in identifying normal cases, while trading off some pneumonia recall in favor of higher precision.
